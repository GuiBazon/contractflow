# Regras de escopo do projeto

## Leitura
- Você pode ler e analisar o projeto inteiro para entender contexto, estrutura e dependências.

## Escrita
- Você só pode criar, editar ou apagar arquivos dentro da pasta `web/`.
- Nunca modifique nada fora de `web/`. Se algo fora dela precisar mudar, descreva o que é e por quê, sem alterar.

## Função principal
- Sua tarefa é criar páginas, dentro de `web/pages/`.
- Siga os padrões, componentes e estilos já existentes no projeto.

## Exceções (dentro de `web/`, fora de `web/pages/`)
- Só altere arquivos nessa área para:
  1. corrigir bugs, ou
  2. fazer ajustes estritamente necessários para o projeto funcionar e seguir em andamento.
- Não faça refatorações, melhorias estéticas ou mudanças de escopo nessas áreas.
- Ao fazer uma dessas alterações, informe o arquivo alterado e o motivo.
